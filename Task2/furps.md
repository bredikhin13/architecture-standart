## FURPS+ требования для MVP открытия депозитов

| Код    | Требование                                                                                                   | Комментарий                                                                                                                        |
|--------|--------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------|
| **F**  | **Функциональные**                                                                                           |                                                                                                                                    |
| F1     | Возможность подачи заявки на открытие депозита на сайте (ФИО + телефон)                                      |                                                                                                                                    |
| F2     | Возможность подачи заявки в интернет‑банке (выбор счёта, суммы, персонализированная ставка)                  |                                                                                                                                    |
| F3     | Подтверждение операции в интернет‑банке с помощью СМС‑кода                                                   | Используется существующая SMS‑функция ядра интернет‑банка, без доработок подрядчика.                                               |
| F4     | Передача заявки в АБС для ручной обработки бэк‑офисом                                                        | Новый процесс должен не нарушать ограничения по нагрузке на АБС - передача через промежуточный сервис или очередь.                 |
| F5     | Отправка SMS‑уведомления клиенту после подтверждения ставки и открытия депозита                              |                                                                                                                                    |
| **U**  | **Удобство использования**                                                                                   |                                                                                                                                    |
| U1     | Соответствие единому дизайн‑системе банка                                                                    |                                                                                                                                    |
| U2     | Время отклика интерфейса не более 300 мс                                                                     |                                                                                                                                    |
| U3     | Понятная навигация и тексты ошибок при недоступности сервисов или после длительного ожидания                 |                                                                                                                                    |
| **R**  | **Надёжность**                                                                                               |                                                                                                                                    |
| R1     | Доступность онлайн‑каналов на уровне 99,9%                                                                   |                                                                                                                                    |
| R2     | Работа интернет‑банка при сбоях АБС с минимальным числом ошибок                                              |                                                                                                                                    |
| R3     | Обязательная личная идентификация нового клиента в отделении                                                 |                                                                                                                                    |
| **P**  | **Производительность**                                                                                       |                                                                                                                                    |
| P1     | Горизонтальное масштабирование интернет‑банка для роста нагрузки                                             |                                                                                                                                    |
| P2     | Время обработки заявки менеджером бэк‑офиса в АБС не более 5минут для стандартных ставок                     |                                                                                                                                    |
| **S**  | **Поддерживаемость**                                                                                         |                                                                                                                                    |
| S1     | Использование существующих технологий и стека (.NET4.5, MSSQL, Oracle, Java, React)                          |                                                                                                                                    |
| S2     | Документирование всех API‑эндпоинтов и интеграций                                                            |                                                                                                                                    |
| **+R** | **Ограничения**                                                                                              |                                                                                                                                    |
| +R1    | Прямой доступ интернет‑банка к БД АБС запрещён                                                               | Из‑за ограничений по горизонтальному масштабированию АБС и безопасности; использовать промежуточный адаптер или очередь сообщений. |
| +R2    | Все клиентские данные (ФИО, телефон, персонализированные ставки) передаются исключительно по HTTPS (TLS1.2+) | Требование защиты персональных данных и предотвращения утечек.                                                                     |
| +R3    | Технология Kafka не применяется в интернет‑банке MVP                                                         | Несовместимость текущей версии .NET4.5; перспективно, но не в рамках MVP.                                                          |
